## 1. Weco 4-Level Framework

| Level | Nome | Definição operacional |
|---|---|---|
| **L0** | Delegation | Autonomous loop completo mas mais lento que humano com ferramentas Level 0 |
| **L1** | Net Positive | Sistema melhora mais rápido que humano com mesmas ferramentas |
| **L2** | Ignition | v2 é melhor improver que v1 (v3 produzido por v2 > o que v1 conseguiria no mesmo budget) |
| **L3** | Inflection | Loop vence diminishing returns — ganhos por generation crescem em vez de encolher |

**4 critérios pra classificar** (Weco):
1. Fair human baseline (humano com quaisquer ferramentas EXCETO o sistema self-improving)
2. Sustained multi-step trend (não 1 jump)
3. Generalization cross-benchmark
4. Fixed physical budget (wall-clock + $ é o par canônico)

**Estado 2026**: nenhum sistema published passou L2. Weco declinou certificar AIDE² L2 (asymptotic convergence + noise margin).

Fonte: https://www.weco.ai/blog/4-levels-of-recursive-self-improvement

## 4. Evaluation metrics (como provar L0→L3)

### 4.1 Human baseline — RE-Bench é o gold standard

| Bench | arXiv | Setup | Level testado |
|---|---|---|---|
| **RE-Bench (METR)** | 2411.15114 | 71 humanos × 8h em 7 envs, agents+humans mesmo wall-clock (4h/8h/32h) | L0/L1 gatekeeper |
| MLE-Bench (OpenAI) | 2410.07095 | Medal-tier rate vs Kaggle public LB | L0. o1+AIDE 16.9% bronze |
| ALE-Bench (Sakana) | 2506.09050 | AtCoder Heuristic, long-horizon | L0 |

**Result headline RE-Bench**: agent 4× humano @ 2h, humano 2× agent @ 32h.

### 4.2 Sustained multi-step trends

| Sistema | Rounds | Curve |
|---|---|---|
| **AIDE² (Weco)** | 7 versões / 100 steps / 8 dias | Reward-hack 63→34%, +0.053 MLE-Lite p=0.0024 |
| **DGM** | ~80 gen archive | SWE 20→50%, Polyglot 14.2→30.7% |
| **SICA** | ~50 iter | SWE Verified 17→53% |

DGM + SICA = clearest sustained trends.

### 4.3 Budget canônico

**Wall-clock + $ é o pair** (FLOPs quase nunca reported for agents).

- RE-Bench: ≤6× H100, 2000h total
- WeatherBench-2 AIDE²: $15/agent fixo
- ARC-AGI-2 Kaggle: $50/submission, Kaggle GPU $0.20/task

### 4.4 v2 > v1 test (L2)

Só Weco tenta: AIDE⁴⁷ vs AIDEhuman mesmo task. AIDE⁴⁷ hit em ~20 steps vs 40. **Weco recusou L2 cert** (noise margin wide).

### 4.5 Diminishing returns detection

Papers: **Illusion of Diminishing Returns** (2509.09677), **AI Scaling Wall** (2512.20264).

Standard: fit `gain = a·gen^(-b)` ou `a·e^(-bt)`, report expoente b. b>0 = diminishing, b<0 = accelerating (L3).

## 6. Recomendações Caracal RSI extension

### 6.1 Best-fit L1 recipe (viable Kaggle T4 x2)

1. **Inner loop**: Self-Rewarding LM (lucidrains ref) + Qwen2.5-3B + LoRA r=32 + unsloth 4-bit
2. **Outer loop**: DGM/SICA archive-based scaffold evolution — swap SWE-bench harness pra CTF/CVE harness
3. **Sub-module**: OpenEvolve pra evolução de payload/exploit programs (Qwen-3B inner mutator via vLLM, $0.01/iter)
4. **Verifier**: RLVR verifiable reward (exploit-succeeds / CTF flag) em vez de LLM-judge (3B capacity limit)

### 6.2 L2 aspirational

DGM/HGM archive-based scaffold evolution com CTF/pentest harness. Ver **CyberEvolver** patterns (preprint domain-specific).

### 6.3 Evaluation methodology

- **L0/L1 gate**: RE-Bench methodology (matched wall-clock + $) adaptada pra cybersec
- **Sustained trend**: DGM-style archive tree, plot N-round curve
- **Generalization**: hold-out cyber (SecBench não seen) + non-cyber (LiveCodeBench monthly)
- **L3 signal**: power-law fit gain-vs-gen, monitor expoente b

### 6.4 Avoid

- Pure prompt-only loops (Promptbreeder, Self-Refine) — 3B capacity muito pequena pra judge meta-reasoning
- AZR/ML-Agent — precisa H100+ full-param RL
- Wrap outer loop com framework pesado (LangGraph) — regra Pedro "in-model, não framework"
